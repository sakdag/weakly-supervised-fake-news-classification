# Notebooks

- `analysis/` — data exploration, threshold/percentile figures, weak-labeler run analysis  
- `experiments/` — classical LF-model trials and RoBERTa/BERT end-model experiments  
- `figures/` — cached CSV stats used when regenerating plots  

Run notebooks from the repository root with `PYTHONPATH=.` (or an equivalent kernel) so `from src...` imports resolve.

Third-party tutorial / Kaggle scratch notebooks were removed for the public cleanup.
